# 🚀 Interactive Developer Portfolio

A premium, highly responsive, and SEO-optimized professional portfolio website designed for full-stack developers and computer science professionals. Hand-crafted using clean, modern, and standard web technologies.

🔗 **Live Demo:** [personal-portfolio-intern.netlify.app](https://personal-portfolio-intern.netlify.app/)

---

## ✨ Features

- 🌓 **Dynamic Theme Engine**
  Seamlessly toggle between a modern white-themed interface and a sleek dark mode. The theme preference is automatically persisted across sessions using `localStorage`.

- 📱 **Pixel-Perfect Responsiveness**
  Completely redesigned with tailored media queries and responsive styling. The layout scales fluidly from small mobile displays (like iPhone SE) up to wide desktop screens.

- 📂 **Dynamic Project Filters & Detail Modals**
  Explore selected works dynamically categorized by tech stack (Full Stack, Frontend, Utilities). Click "Learn More" to open a clean overlay detail modal populated with features and stack specs.

- 📝 **Printable Interactive Resume**
  Includes a fully structured interactive resume modal. Features a built-in print command with customized CSS `@media print` formatting to print or save a clean PDF resume directly.

- 💬 **WhatsApp Redirection Form**
  Interactive contact form with real-time field validation. Automatically formats input entries and redirects users to a pre-filled WhatsApp message box.

- 📈 **SEO & Social Media Previews**
  Pre-configured with standard Open Graph (OG) tags, search engine keywords, favicon settings, and responsive semantic tags for quick loading and social page styling.

---

## 🛠️ Tech Stack & Resources

- **Core:** Semantic HTML5, Vanilla CSS3, Vanilla ES6 JavaScript
- **Typography:** [Outfit & Inter](https://fonts.google.com/) via Google Fonts API
- **Icons:** [Boxicons CDN v2.1.4](https://boxicons.com/)
- **Print:** Native CSS Print Document Styles

## 🎨 Layout Design Details

- **Typography Hierarchy:** Modern headings styled with Outfit font, supported by a highly legible sans-serif font Inter for text copy.
- **Micro-Animations:** Fluid scaling transitions on hover, floating badge animations in the hero frame, and a customized intersection observer scroll reveal effect.
- **Glassmorphism:** Elegant header blur effects using CSS `backdrop-filter` on scroll tracking.
